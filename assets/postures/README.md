# Ilustraciones de posturas

Estas siete ilustraciones fueron generadas específicamente para Respiración Yogui el 4 de agosto de 2026 con la herramienta de generación de imágenes de OpenAI. No se incorporaron fotografías ni ilustraciones de terceros.

Todas usan la misma dirección visual: ilustración educativa sobre fondo claro, persona adulta con remera verde y pantalón oscuro, silla de oficina, cuerpo completo y flechas azules para indicar la dirección del movimiento. No incluyen texto, marcas ni afirmaciones de salud.

Correspondencia:

- `seated.webp`: Sentada.
- `arms-up.webp`: Brazos arriba.
- `twist.webp`: Torsión.
- `forward-fold.webp`: Flexión hacia adelante.
- `side-stretch.webp`: Lateral.
- `heart-opener.webp`: Apertura de pecho.
- `shoulders.webp`: Hombros.

El guion y las alternativas visibles provienen de las posturas base definidas para la aplicación. Antes de presentar este contenido como validado profesionalmente, su redacción y ejecución deben contar con la revisión de una persona calificada en movimiento o yoga.
